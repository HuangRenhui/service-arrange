# 服务编排平台 · 文档说明

本目录是 **服务编排平台（`service-arrange`）v1.0** 的正式手册。仓库根目录的 `README.md` 只做快速上手，本目录承载完整的**设计说明、规范契约、实现现状与运维指引**。

阅读本手册前请注意三点：**DSL 是全系统唯一契约**，前端导出与后端解析都以 [DSL规范](02-DSL规范.md) 为准；**后端核心引擎位于 `engine` 模块**（无 Web 层），Web 接口在 `web` 模块；**当前代码并非全部可用**，哪些能跑、哪些不能，以 [功能清单](09-功能清单.md) 与 [项目现状](10-项目现状.md) 为准，不要以设计文档为实现的保证。
