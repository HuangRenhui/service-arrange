## §附3 可用能力最小闭环

当前代码下**真正能跑通**的场景：

```
开始节点（声明入参 Schema）
  → 数据映射（把入参/全局参数/上游输出映射成下游入参）
    → HTTP 调用（真实发起 HTTP 请求，按状态码判定成败）
      → 结束节点（按出参 Schema 映射返回值）
```

**推荐验证路径**：

1. 打开 `frontend/index.html` → 「加载示例 → 示例 1」；
2. 点「校验流程」确认通过；
3. 点「导出 DSL」复制 JSON；
4. 覆盖到 `backend/web/src/main/resources/hrh_http.json`；
5. 重启后端，调用 `POST /servicearrange/inst/run/or/getResult/{planId}`。
