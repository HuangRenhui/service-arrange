2.循环线连接第一个节点
3.while do 或 do while 的循环线问题
4.算子类型：
    算子映射：上下节点间字段映射
    算子结果：获取上一个父节点的结果
    决策算子：进行循环判断需要用到的算子
    list聚合算子：抽取封装成一个集合
    数组提取封装（过滤）：将数组中特定字段提取出来重新封装成新数组
    数组聚合：条件判断，A、B两个数组的选择字段进行对比，所有选择对比字段值相同，将B那行数值添加到A中
    数组提取处理：提取数组指定字段
        {
        	"jsonpathMapping": "#pno_f23d8b08-73cc-4f6d-b64d-9186e24a3870$result",

        	"idx": "#dynamicParams_$dindex",
        	"selecFiled": "#pno_f23d8b08-73cc-4f6d-b64d-9186e24a3870$result"
        }
    数组长度：获取数组的长度
    对象封装为数组：抽取封装成数组
        {
			"jsonpathMapping": [{

		}
    默认规则：直接根据表达式获取数值，并根据类型转换输出对应数值

    数组添加：将表达式结果组装成一个字符串
    shell算子：执行shell脚本或jar脚本
    睡眠算子：执行睡眠指定时间
    开始算子：直接成功
    结束算子：获取最后算子结果，进行数据映射，最后结果为实例运行结果
